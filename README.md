

# 📊 Digital Marketing Campaign Performance Analysis

## 📌 Project Overview

This project focuses on analyzing digital marketing campaign performance using **Power BI, Microsoft Excel, and SQL**. The goal is to evaluate campaign effectiveness, monitor key performance indicators (KPIs), and generate meaningful insights from marketing data.

An interactive Power BI dashboard was developed to visualize campaign performance, track marketing expenses, and understand how campaigns contribute to conversions and revenue.

## 🎯 Project Objectives

- Analyze digital marketing campaign performance.
- Track key metrics such as clicks, impressions, conversions, and revenue.
- Calculate and monitor CTR, CPC, CPA, and ROI.
- Evaluate marketing spend and campaign effectiveness.
- Create interactive visualizations for better data interpretation.
- Support data-driven marketing decisions through performance analysis.

## 🛠️ Tools & Technologies

- **Power BI Desktop:** Dashboard development, data visualization, and KPI tracking.
- **Microsoft Excel:** Data cleaning, organization, and preliminary analysis.
- **SQL:** Data querying and analysis.

## 📈 Key Performance Indicators (KPIs)

| KPI | Description |
|---|---|
| Impressions | Number of times an advertisement was displayed. |
| Clicks | Number of times users clicked on an advertisement. |
| CTR (Click-Through Rate) | Percentage of impressions that resulted in clicks. |
| CPC (Cost Per Click) | Average cost incurred for each click. |
| Conversions | Number of desired actions completed by users. |
| CPA (Cost Per Acquisition) | Average cost incurred for each conversion. |
| Revenue | Total revenue generated by the campaigns. |
| ROI (Return on Investment) | Measures the return generated relative to the investment. |
| Ad Spend | Total amount spent on advertising campaigns. |

## 📊 Dashboard Features

- Interactive dashboard for monitoring campaign performance.
- KPI cards displaying essential marketing metrics.
- Visual analysis of clicks, impressions, conversions, and revenue.
- Tracking of advertising costs and campaign efficiency.
- Performance evaluation using CTR, CPC, CPA, and ROI.
- Clear visual representation of marketing data for easier interpretation.
